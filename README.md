# Freelance Dashboard

This is a project dedicated to learning React and Next.JS, I want to create an online application that I can use for my freelance business to manage, and track my monthly invoices.

At the moment I have a manual python script; however, it will be great to learn how to create this for React.

## Update while in development

This project is going really well so far, the JSX and React components are becoming very intuitive, and I am loving learning the syntax and concepts underlying it.

I am looking forward to polishing it up, and then either learning a front end framework like vue, to create the next project, or going React native.
